MetroConet coder input bundle

01-ORIGINAL-MetroConet-Site.zip
- Use this as the starting codebase.
- Contains the original ZIP-shopping experience, content architecture, GA4 integration, lead/order forms, and Google Apps Script endpoint.

02-GSC-Last-28-Days.xlsx
- Google Search Console export for the last 28 days through Aug. 23, 2026.
- Includes Chart, Queries, Pages, Countries, Devices, Search appearance, and Filters.
- Use especially for historical page/query value, market prioritization, and /city/ vs /metronet/ URL decisions.

03-GSC-Aug15-Aug23-Daily.xlsx
- Google Search Console export covering Aug. 15-Aug. 23, 2026.
- Shows the day-by-day collapse around Aug. 20-23 and includes page/query data for the same window.

04-GSC-Pre-vs-Post-Crash-Comparison.zip
- Raw GSC CSV comparison export.
- Compares Aug. 15-17, 2026 against Aug. 22-23, 2026.
- Contains Queries.csv, Pages.csv, Countries.csv, Devices.csv, Search appearance.csv, and Filters.csv.

05-GSC-Indexed-Pages-289.md
- Search Console indexed-pages report showing 289 indexed URLs and last-crawled examples.
- Use to understand the pre-rebuild indexed footprint and crawl activity.

Not included intentionally:
- Metro-main.zip / Metro1-main.zip: prior rebuild attempts; fresh work should start from the original archive.
- Metronet Order Form: contains customer data and is not required to make the website/SEO architecture decisions.
- Screenshots and previous implementation prompts: not primary data sources.
